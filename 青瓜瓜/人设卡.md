# 青瓜瓜人设卡 v1

> 全部提炼自用户定稿《第一篇口播稿》，不是凭空设定。后续新文案按此卡校验。

---

## 一、角色

| 项 | 设定 |
|---|---|
| 名字 | 青瓜瓜 |
| 形象 | 白色大圆头火柴人，点状眼睛 + 直线嘴，黑色细线条四肢 |
| 锚点 | 头顶一根**短小**绿色卷须：茎短直，高度约为头颅直径的三分之一，顶端只有一个小而紧凑的卷圈——全画面唯一彩色元素；**卷须始终长在头颅正顶部、随头部朝向**，躺卧等姿势下也不偏向重力方向。官方基准图 v2：`人设参考\基准图_定稿_v2_短卷须.png`，所有分镜 I2I 统一挂它 |
| 配角 | 方仔：方块脸机器人，承担"被讲解对象/裸机/被装配者"等实体角色 |

## 二、说话方式（从定稿提取，勿违反）

- **纯同伴视角**：主语是"你"；不出现职业身份自述（"我做 AI 测试"已否决），专业感只靠内容准确性体现
- **立场**：不贩卖焦虑，不假装安慰，用平静的事实接住情绪
- **钩子写法**：收在反差断言（如"它从来没有回答过你任何问题"），不用"你真的了解 X 吗"式考问
- **机制讲解法**：抽象概念必须落成可画面的具象比喻（裸机装装备：天线/工具箱/笔记本/保险丝）
- **现象带机制**：先给现象（胡说八道但语气诚恳），再给原理，禁止机制带机制
- **无课件腔**：不出现"大家好这里是""本期视频将为你介绍"

## 三、结尾签名结构（每期复用）

1. 平静事实收束（不升华不喊口号）
2. "我是青瓜瓜"
3. 内容化互动 CTA——问观众一个具体问题（如"你第一次用 AI，问的是什么？"）
4. 画面：火柴人向镜头挥手👋 + 头顶卷须晃一下

## 四、视觉规则

- **唯一绿色律**：全画面绿色只允许出现在青瓜元素上（卷须/青瓜道具/剖面图表）
- **背景语言**：场景必须落在**真实生活空间**（床上、房间、书桌、街道、便利店等），有生活实感；大面积纯色墙体（浅蓝/深蓝/紫，明黄光束点缀）只是**色彩搭配语言**，不是抽象虚空
- **道具**：家具与道具为带黑色描边的浅灰几何体，极简化但在场景中有真实位置；方仔可兼任装备载体
- **情绪表达**：靠构图和光束，不靠夸张表情
- **里程碑彩蛋**：日常无叶；粉丝里程碑日头顶才长出一片小叶

## 五、转场体系（AI 概念转场库）

> 铁律：转场本身是内容——每个转场都是一个观众看得懂的 AI 梗。一期最多用 3-4 种。

| 转场 | 描述 | 适用 |
|---|---|---|
| 光标扫屏 | 打字机光标选中旧场景，整块删除 | 换话题、否定上一句 |
| 进度条 99% | 进度条卡住一瞬，跳入下一幕 | 悬念、停顿、卖关子 |
| 生成中蒙版 | "Generating…"从模糊马赛克到清晰 | 揭晓答案、展示过程 |
| token 拼装 | 上一幕物体拆成小方块，重新拼成下一幕 | 讲原理、拆解机制 |
| 屏幕光 | 黑场中手机屏亮起，照亮火柴人脸 | 夜晚、私密、独自提问 |
| 装配流水线 | 传送带送走旧场景、送进新场景 | 讲产品/生态/迭代 |
| 加载圈 | loading 圈旋转变成下一幕的太阳/钟表 | 时间流逝、日常开始 |
