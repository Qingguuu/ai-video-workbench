# 需求文档：抖音视频制作-发布一体化系统（独立工作台）

> 状态：已确认（2026-10-25）

## 背景

- **imagegen**：完整视频生产流水线（生图 generate.py → 配音 voice.py → 字幕 subtitle.py → 合成 video.py → 发布 publish.py），命令行驱动，产出在 `outputs/`（图）与 `build/<episode>/`（成片）。
- **Easel**：OpenClaw 工作台，体量过大、结构不利于完全掌控，**只作为结构与代码参考**；其中 `douyin_publish.py`（Playwright + 持久化登录态）可复用。
- 两者互不打通，制作视频需手动逐步执行命令行。

## 目标

**新建一个独立的轻量 Web 工作台**（不在 Easel 中开发、不依赖 Easel 运行）：
页面输入创作主题并提交后，**视频制作一键完成**——分镜生成、生图、配音、字幕、合成全自动执行，无需任何中途手动操作；成片在页面预览、编辑标题/话题、确认后发布到抖音。代码规模小、结构清晰，用户可完全掌控。

## 已确认决策

1. 形态：独立轻量系统（新前端 + 新后端服务），Easel 代码可拷贝复用但不作为运行时依赖
2. 输入：用户只填主题/创意，分镜脚本、生图提示词、配音文案由 AI 全部生成
3. 发布：复用 Easel 的 `douyin_publish.py`（Playwright + 持久化登录态）方案，拷贝/适配进新系统运行
4. 自动化：生成完成后页面预览成片、人工确认后才发布
5. 发布入口不限于系统生成的视频：页面支持**手动上传本地视频**，走同一发布模块发布

## 范围内

- 新建独立项目目录（前后端同仓），技术栈在计划阶段选定
- 前端：创作发起页（主题输入 → 生成进度展示 → 分镜/成片预览 → 发布信息编辑 → 发布）
- 后端：任务编排器，按序调用 LLM 生成分镜 + imagegen 各脚本（generate/voice/subtitle/video）
- 发布模块：适配 `douyin_publish.py`，复用已有抖音登录 profile；同时支持手动上传本地视频发布
- 发布记录与全流程产物（分镜 json/图片/成片/发布结果）落盘可追溯

## 范围外（暂定）

- 不在 Easel 中添加任何功能，不修改 imagegen 核心生成算法
- 不做多平台发布（仅抖音）
- 不做用户体系/多账号/权限
- 不做批量队列与定时发布（记入待办池）

## 验收标准（草稿）

1. 页面填写主题并提交后，制作全程一键完成（分镜→生图→配音→字幕→合成无任何中途操作），无需命令行
2. 页面实时展示当前步骤与进度，失败有明确报错信息
3. 成片可在页面预览，可编辑标题/话题，确认后执行发布
4. 发布成功（或明确提示需扫码/人工介入），发布记录可查
5. 新系统代码量小、目录清晰，不引入 Easel 运行时依赖
