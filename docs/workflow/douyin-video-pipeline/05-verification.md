### F5 手动上传视频发布 ✅
| 验收点 | 结果 | 证据 |
|---|---|---|
| 仅 mp4/mov 且 ≤2GB | ✅ | .avi 上传被拒 400「仅支持 mp4 / mov 格式」；>2GB 流式中断 413 |
| 上传后预览/编辑/发布一致 | ✅ | 上传 10MB mp4 → 任务 ep35e06db4（type=upload, status=ready），视频接口 206 |
| 上传任务进列表+发布记录可查 | ✅ | 列表页显示「上传」类型；publish_records 按任务可查 |

### F6 任务与发布记录 ✅
| 验收点 | 结果 | 证据 |
|---|---|---|
| 列表与状态一致、刷新不丢 | ✅ | SQLite 持久化；列表页显示类型/状态徽标/时间 |

| 上传任务可追溯 | ✅ | data/uploads/<uuid>.mp4 + 发布记录 |

### 边界与异常
| 场景 | 结果 |
|---|---|
| 同一时间并发提交 | ✅ 单任务锁：第二个提交 409「已有制作任务进行中」（实测） |
| 服务重启 | ✅ startup 把 making→interrupted，页面可重试（实测重启恢复逻辑） |
| 登录态失效/需扫码 | ✅ headed 弹窗 + status 文件轮询 + sms code 回填（机制就绪） |
| 上传格式/大小不符 | ✅ 实测拦截 |
