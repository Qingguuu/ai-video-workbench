# 功能规格：抖音视频制作-发布一体化系统

> 状态：已确认（2026-10-25，含 F5 手动上传发布增补）

## 功能点列表

### F1 一键制作（创作发起）
用户在页面填写**主题**（必填，≤200字）与**补充说明**（选填），提交后系统自动依次执行：
分镜生成（LLM）→ 生图 → 配音 → 字幕 → 视频合成。
全程无中途人工操作。

验收标准：
- 主题为空或超长时提交被拦截并提示
- 提交后页面进入进度视图，实时显示当前步骤（5 步）与整体状态
- 制作完成后自动进入预览视图，无需手动刷新流程

### F2 进度与状态展示
制作过程按步骤展示：进行中/已完成/失败，每步显示开始时间与耗时。

验收标准：
- 页面展示的步骤状态与后台实际执行一致
- 任一步骤失败：任务标记失败，页面显示失败步骤、错误原因；支持**从失败步骤重试**（已完成的产物不重跑）

### F3 成片预览与发布信息编辑
制作完成后，页面内嵌播放器预览成片；展示并允许编辑**标题**（默认由分镜生成）与**话题**（可增删）。

验收标准：
- 成片可在页面直接播放（音视频正常）
- 标题可编辑，非空校验；话题至少 1 个、可增删
- 未确认发布前，不会触发任何上传行为

### F4 抖音发布
确认后调用发布模块（Playwright + 持久化登录态）：上传成片、填标题话题、发布。
发布过程在页面显示状态（上传中→发布中→成功/失败）。

验收标准：
- 登录态有效时：上传并发布成功，页面显示成功及发布结果
- 登录态失效时：明确提示需要扫码登录，提供「重新登录」操作入口，登录后可继续发布
- 发布失败时：显示失败原因，可重试发布（成片无需重做）

### F5 手动上传视频发布
页面提供独立入口：选择本地视频文件上传（mp4/mov，≤2GB），进入与 F3 相同的预览与标题/话题编辑界面，确认后走 F4 同一发布模块发布。上传的视频同样作为一个任务进入任务列表（类型标记为「上传」）。

验收标准：
- 仅允许 mp4/mov 且 ≤2GB，超出被拦截并提示原因
- 上传完成后可预览、编辑标题/话题，确认后发布流程与生成视频完全一致
- 上传发布的任务在任务列表中可见（类型「上传」），发布记录同样可查

### F6 任务与发布记录
提供任务列表页：每个任务显示主题、创建时间、类型（生成/上传）、状态（制作中/待发布/已发布/失败）、成片入口。发布成功后记录发布时间与结果。

验收标准：
- 任务列表与实际任务状态一致，刷新不丢失
- 生成任务与上传任务均可追溯：生成任务的分镜 json、图片、配音、字幕、成片、发布记录；上传任务的视频文件与发布记录

## 边界与异常场景

| 场景 | 处理 |
|---|---|
| LLM 分镜生成失败/超时 | 任务失败，显示原因，可从该步重试 |
| 生图 API 失败/部分分镜失败 | 失败步骤标记，重试仅重新生成失败分镜 |
| TTS / ffmpeg 合成失败 | 同上，可从失败步骤重试 |
| 同一时间并发提交 | 同一时间仅允许 1 个制作任务运行，运行中禁止再次提交，页面给出提示 |
| 发布中页面关闭/断网 | 后台任务继续执行，重新打开页面可见最终状态 |
| 登录态失效/需扫码 | 发布暂停，提示人工扫码，完成后继续 |
| 上传文件格式/大小不符 | 提交时拦截并提示（仅 mp4/mov，≤2GB） |
| 服务重启 | 进行中的任务标记为「已中断」，可从失败步骤重试；已上传待发布的视频不受影响 |
